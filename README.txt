BLUSHCART V3 — SHOPPING FLOW DEMO

HOW TO OPEN
1. Extract the ZIP.
2. Keep every file together in the same folder.
3. Double-click index.html.
4. Use Chrome or Edge.

WHAT WORKS
- Homepage
- Shop page
- Category filters
- Search and sorting
- Product detail page
- Wishlist counter (local browser storage)
- Add to cart
- Quantity update and remove
- Cart persists while moving between pages (localStorage)
- Free-shipping demo rule above ₹599
- Checkout form
- Cash-on-delivery / online-payment placeholder selection
- Demo order confirmation page
- Responsive layout for desktop and mobile

IMPORTANT
This is still a FRONT-END DEMO. It does NOT have a real database, admin panel, login system, payment gateway, inventory sync, emails/SMS, taxes, courier integration or live order management.
Do not put payment keys, passwords or secret API keys in HTML/JS files.
Before launch, replace all demo product information and review product claims/ingredients/policies for accuracy and compliance.

V6 ADMIN DASHBOARD
- Open admin.html for the local demo admin console.
- Add/edit/hide/delete demo products and stock values.
- Product changes are stored in browser localStorage and appear on storefront after refresh.
- Admin shows local demo order count/revenue and recent checkout orders.
- This is NOT a secure production admin panel: no server login/database is connected yet.
